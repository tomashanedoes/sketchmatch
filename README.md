# Tekenmoment (SketchMatch)

A calm, non-competitive Progressive Web App with drawing prompts for paper and pencil. Shaped with Waldorf / vrijeschool ideas in mind: your own pace, imagination, and the making itself — no scores, no leaderboards.

**Live:** https://tomashanedoes.github.io/sketchmatch/

The UI is in Dutch. Progress and settings stay on the device.

## Install on your phone

No app store. Open the live link, then add it to the home screen.

### Android (Chrome)

1. Open [tomashanedoes.github.io/sketchmatch](https://tomashanedoes.github.io/sketchmatch/)
2. Tap the browser menu (⋮)
3. Choose **Install app** or **Add to Home screen**
4. Confirm — Tekenmoment appears like a normal app icon

### iPhone / iPad (Safari)

1. Open the live link in **Safari** (not Chrome)
2. Tap **Share**
3. Tap **Add to Home Screen**, then **Add**
4. Open it from the home screen next time

### Desktop (optional)

Chrome or Edge may show an install icon in the address bar.

## How it works

1. Choose a collection for younger hands or for adults
2. Take paper and a pencil
3. Follow the drawing invitation at your own pace
4. When you are done, choose another prompt — or stop

Adults can use an optional soft timer (free play, 10 or 20 minutes). It is a gentle reminder, not a race. At the end you only see a short look-back: finished and skipped prompts, no score.

Settings cover read-aloud, soft sounds, calm motion, default soft-timer and topics per collection. Everything is stored locally.
